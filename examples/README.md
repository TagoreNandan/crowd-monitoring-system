# examples/

Drop your own test images/videos here and point the CLI at them, e.g.:

```
python scripts/run_image.py --input examples/your_photo.jpg --output output/
```

No sample media ships in this repository (crowd photos/videos suitable for a
public demo carry their own licensing, and none of the reference projects'
assets are redistributable here) -- bring your own input, or use a webcam /
short clip you have rights to.
